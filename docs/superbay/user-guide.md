# SuperBay 使用说明

## 第一次使用

1. 启动 SuperBay，选择存放工具的根目录，例如 `D:\Pentest`。应选择包含各个分类的那一层目录。
2. 在左侧选择分类，在中间搜索或选择工具，右侧查看命令、环境和笔记。
3. 点击“启动”。第一次使用先检查启动方式；发现多个入口时，点击“自动识别”选择正确入口。
4. 新增工具后会自动更新，也可以按 `F5` 重新扫描。

顶栏目录下拉菜单用于切换已保存的目录入口。工具目录可以放在任意磁盘，推荐与启动器程序分开放置。

按其他职业或用途规划目录，请参考 [目录规划指南](directory-planning.md)。

## 目录推荐命名

分类推荐使用 **字母-两位编号-分类名称**，例如 `B-10-信息收集`。字母与编号方便文件管理器排序，SuperBay 显示分类时会隐藏 `B-10-`，只显示“信息收集”。`A-工具箱` 也支持隐藏前缀；单独的 `01-工具箱` 不会自动隐藏编号。命名是整理建议，不是运行要求。

下面是一套可直接参考的分类：

```text
D:\Pentest\
├── A-00-字典\
├── A-01-工具箱\
├── B-10-信息收集\
│   ├── OneForAll\
│   │   ├── oneforall.py
│   │   ├── requirements.txt
│   │   └── NOTE.md
│   └── 域名枚举\
│       └── subfinder\
│           └── subfinder.exe
├── C-20-漏洞利用\
├── C-30-扫描器\
├── D-40-Web安全\
├── D-41-服务攻击\
├── E-50-移动安全\
├── F-60-内网渗透\
├── G-70-免杀\
├── H-80-代码审计\
├── I-90-杂项工具\
├── I-91-插件\
├── J-00-挖洞笔记\
├── J-01-靶场\
└── Z-99-归档\
```

按自己的工具数量删减即可，不必创建全部分类。编号建议留出间隔，便于以后插入新分类。

工具文件夹推荐保留项目原名，例如 `OneForAll`、`subfinder`，一项工具一个文件夹。需要同时保留多个版本时，可使用 `工具名-版本号`。自写脚本和启动脚本尽量使用简短英文名；中文分类可以正常使用，部分第三方工具对空格或中文路径支持有限时，可将该工具放到纯英文路径。

不要随意改动工具内部的文件夹结构。命令已经保存后再移动或重命名工具目录，通过「整理工具」操作会同步工具配置、运行次数和命令中的对应路径；在资源管理器中操作后仍需重新定位或检查配置。

## 分类层级与扫描

支持嵌套分类，默认扫描深度为 2，可在设置中调整，范围为 1–16。超过扫描深度的目录作为一个条目显示。

包含可执行文件、脚本或项目标记（如 `requirements.txt`、`package.json`、`.git`）的文件夹会识别为工具，并保持整体，不再拆成下级分类。因此，分类目录里尽量只放工具文件夹，把启动脚本放进对应工具目录。

普通目录可能展开为分类；只想将一个资料目录作为条目时，可通过扫描深度控制。空分类不会显示。隐藏目录及 `node_modules`、`__pycache__`、`venv`、`vendor`、`SuperGUI`、`SuperBay` 等目录会跳过。根目录直属的普通文件也可以显示。

## “编辑启动”和“自动识别”有什么区别

| 入口 | 用途 | 什么时候使用 |
| --- | --- | --- |
| 编辑启动 | 修改默认启动命令和运行方式（cmd / PowerShell），实时预览最终命令行 | 大多数情况 |
| 自动识别 | 扫描工具目录，识别 EXE、脚本和 `.lnk` 快捷方式并写入默认命令 | 第一次添加工具，或入口发生变化 |
| 绑定环境 | 为当前工具选择运行环境 | 工具需要指定 Python、Java 或 Node 版本 |

例如，默认命令填写 `python oneforall.py`；需要临时换参数时按 `Shift+Enter` 带参数启动，输入的参数会被记住。启动命令留空时自动识别主程序，找不到主程序则打开工具目录。

## 日常操作

- 搜索：输入工具名称、标签或笔记关键词；可按 `Ctrl+K` 聚焦搜索。
- 主题：默认跟随 Windows 深浅模式，也可以从顶栏主题菜单手动选择浅色或深色。
- 快速启动：点击“快速启动”按钮打开。
- 启动：选中条目后按 `Enter`；`Ctrl+Enter` 管理员启动；`Shift+Enter` 带参数启动。
- 终端：设置 → 启动 → 终端程序，可选择 WezTerm、Windows Terminal、Alacritty 等；命令类启动会在该终端中打开。Folio 0.4.8 的命令行不能执行命令，暂不支持自动运行工具。
- 常用工具：按 `Ctrl+D` 固定或取消固定。
- 桌面快捷方式：详情面板「信息 → 创建桌面快捷方式」或右键“创建桌面快捷方式”，会按当前启动方式在桌面生成 `.lnk`。
- 程序快捷方式：设置 → 关于 → 创建桌面快捷方式，生成指向 SuperBay 自身的桌面图标；源码运行也可执行 `python tools/create_shortcut.py`。
- 笔记：在详情面板「笔记」页编辑并保存，保存在工具目录的 `NOTE.md`；已有 `00.txt` 时沿用。普通文件条目不支持笔记。
- 退出：关闭窗口会收起到托盘，完全退出请使用托盘菜单“退出”。

## 备份与换电脑

通过“工具管理 → 备份与迁移”导出配置。备份包含目录设置、工具元数据、启动命令、环境绑定和使用记录，不包含工具程序和运行日志。工具目录与笔记需要另外复制，运行环境需要在新电脑安装。

源码运行的数据保存在项目 `config/`；打包版保存在 `%LOCALAPPDATA%/SuperGUI`（兼容原配置目录）。迁移后检查目录路径，以及自定义命令中写死的旧路径。

## 整理工具与详情侧栏

顶部「整理工具」支持导入文件或文件夹、新建分类、重命名、移动到分类和批量追加标签。按 Ctrl / Shift 多选；也可把文件或文件夹拖进主窗口或整理窗口。导入会复制原文件，不覆盖同名目标；大目录在后台复制。完成操作后自动刷新。

详情侧栏分为「启动」「笔记」「信息」：启动页配置默认命令、运行环境和多种启动方案；笔记页独立编辑与预览；信息页查看完整路径、标签、搜索别名和累计次数。顶部「文件」浏览工具内的配置与输出，支持文本预览、文件名筛选、复制路径和在所选目录打开终端。

## 多启动方案与参数模板

详情 → 启动 → 启动方案 → 管理，在左侧选择或新建方案，右侧编辑名称和命令。可以从当前启动命令创建，或复制已有方案。点击「插入参数」中的文本、文件、目录按钮即可添加填写项；cmd / PowerShell 和管理员设置放在「高级选项」。保存后立即生效，点击「保存并运行」可直接使用。切换或关闭时，未保存修改会提示处理。普通默认启动命令继续沿用原行为。

模板仅在启动方案中生效，例如：

```text
python main.py --target {目标} --wordlist "{字典:file}" --output "{输出目录:dir}"
```

`{名称}` 为必填文本，`{名称:file}` / `{名称:dir}` 支持文件或目录选择，也可拖入路径。文件与目录必须存在。含空格的参数应在命令模板中加引号；执行前会展示完整命令。各方案分别记住上次填写的值。

## 中文检索与最近记录

搜索支持名称、拼音、首字母、标签、笔记和自定义别名。例如 `xxsj` 可匹配「信息收集」，`标签:扫描 类型:工具` 可限定范围；文件与目录分别使用 `类型:文件`、`类型:目录`。名称中的直接匹配会高亮。

Ctrl+Alt+K 唤起工作台并聚焦搜索。点击快速启动图标打开面板，空输入时固定项优先，其后按最近使用排序。

「最近」列表支持右键移出单项，或点击「清空最近」清理当前工作区。清理后保留工具、累计启动次数、最后启动时间和运行日志；再次启动会重新进入最近列表。清理状态重启后保留。

## 工具目录约定与大型项目

建议使用「工作区 / 分类 / 工具项目」结构，每个工具一个独立目录。带有 package.json、pyproject.toml、requirements.txt 或 Git 标记的项目保持整体；即使直接放在工作区根目录，也不拆成源码文件。

选择分类默认只显示和搜索当前目录的直接内容，子分类显示为目录入口。需要递归查看或搜索时开启「包含子目录」。「全部」是跨目录汇总视图，范围会在列表上方注明。

已有依赖、希望原地运行的大型项目，优先用「工具管理 → 快捷入口」指向其所在工具集合目录，不复制文件。复制导入默认跳过 node_modules、__pycache__ 和常见检查器缓存，保留源码与依赖清单、锁文件；导入完成后会提示跳过项，新位置需要自行安装依赖。需要完整复制时，可取消整理窗口中的跳过选项。
