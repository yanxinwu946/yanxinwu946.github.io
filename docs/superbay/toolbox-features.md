# 工具工作台功能说明

## 目录快捷入口

顶部目录选择器保存常用目录，一次只展示、监听和搜索当前目录，不做跨目录聚合。通过「工具管理 → 快捷入口」添加、重命名、移除入口；移除入口不删除磁盘文件。

设置中的「工作区 → 管理快捷入口」也能管理目录。更改根目录时会重新扫描并清空当前筛选。

目录可多级嵌套，侧栏分类支持展开和收起。点击父分类默认只展示当前层，子目录作为导航入口；开启「包含子目录」后递归查看和搜索。「全部」保留当前工作区的跨目录汇总。根目录直属文件也会收录。

含启动入口、工程配置或 Git 标记的工具文件夹作为完整工具保留，不继续展开其源码和依赖；普通文档文件夹可逐级浏览。隐藏目录、依赖目录和指向工具目录之外的目录链接会跳过。

## 工具环境、启动入口与配置

工具右键「运行环境」可绑定 Scoop 中具体版本的 Python、Java、Node，启动时只对当前工具生效。默认环境不受修改。

「自动识别」支持 Python、JAR、Node、EXE、批处理、PowerShell 和 Windows 快捷方式（`.lnk`）。唯一候选可直接启动，多个候选需选择后保存。Python 工具存在 `.venv/Scripts/python.exe` 时优先建议项目环境。「编辑启动」提供命令、运行方式与最终命令行预览。详情面板「信息 → 创建桌面快捷方式」或右键「创建桌面快捷方式」会在桌面生成 `.lnk`，按当前启动方式直接运行工具；管理员启动会带上 UAC 提权标记。设置 → 启动 可指定外部终端（WezTerm、Windows Terminal、Alacritty 等），命令类启动会在该终端中运行；Folio 0.4.8 无法通过命令行执行命令，暂不支持。


## 快捷启动

Ctrl+Alt+K 唤起工作台；点击快速启动图标打开面板，搜索范围仅为当前目录。方向键选择条目，Enter 启动。界面提供运行环境、启动方案、工具文件和打开目录入口。Shift+Enter 临时输入参数，Ctrl+Enter 使用管理员权限启动。

## 启动状态与日志

可执行命令默认通过独立控制台工作进程启动，不继承 GUI 的控制台句柄。界面显示启动、运行、退出、失败状态；「工具管理 → 运行记录」查看实时输出、错误和退出结果。指定外部终端时该次启动直接交给终端，运行记录中不包含输出日志。窗口关闭到托盘不影响工具运行。

普通目录或没有可执行入口的文件交给 Windows 打开，此类操作只表示请求已提交，不宣称其关联应用处于运行状态。历史状态未知时会明确标出。

运行记录和日志在本地 `config/launches` 中保存；退出后仍可查阅。环境请求只保存覆盖项，不复制整个父进程环境，并在运行完成后移除。日志及自定义命令可能包含用户自己输入的信息。

## 健康检查

「工具管理 → 健康检查」检查路径、入口歧义、解释器和绑定版本。可重新选择启动入口、绑定环境或重新定位失效工具。自动检查不安装依赖或修改系统环境。缺失工具的元数据保留，供修复使用。

## 备份与迁移

「工具管理 → 备份与迁移」导出 ZIP：包含设置、工具元数据、统计、启动命令和环境绑定，不包含工具文件和运行日志。

导入先生成 `config/before-import-时间.zip`。同路径配置以备份为准，其他工具配置保留。可填写原目录、新目录，迁移路径前缀及环境根目录；自定义命令中写死的绝对路径需重新识别或编辑。工具文件需要自行复制到新电脑，绑定运行环境需要在本机实际安装。

主题与视图立即刷新；快捷键和窗口位置重启后生效。

## 验证

自动测试覆盖目录快捷入口与扫描隔离、入口识别与歧义、备份往返及目录迁移、无效备份保护、环境差异隔离、工作进程退出码和日志、快速面板启动。

另有真实 Windows 启动验证，覆盖含空格的程序路径、带空格的参数、日志输出和非零退出码。

整理工具、参数模板、中文搜索与最近列表清理见 [使用说明](user-guide.md)。
