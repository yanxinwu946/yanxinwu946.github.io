## 收录边界

本站是独立的知识索引，与上述项目无官方隶属关系。中文导读由本站编写；原文链接始终指向原作者。没有搬运文章正文、图片、代码或实验环境，也没有把英文目录标成中文译文。

目录快照来自公开的 HackTricks 中文 SUMMARY、The Hacker Recipes 导航配置与 PayloadsAllTheThings 站点导航。来源链接可能随上游调整；出现失效时，可从对应项目首页继续查找。

搜索索引包含文章标题与有限的中文术语别名，不能代替各知识库的全文搜索。条目分类按关键词辅助整理，少量交叉主题可能出现在其他方向。

## 如何更新

维护者在仓库根目录运行 `python scripts/refresh-hacking.py`，检查目录变化后提交即可。脚本只获取公开目录元数据，不下载正文。更新没有自动定时运行。
