  2. 2

    填写命令，选好运行方式

    确认使用 cmd 还是 PowerShell；需要指定解释器版本时再绑定环境。

  3. 3

    把重复用法存成方案

    为常用命令命名，通过文本、文件、目录按钮插入变化项。

  4. 4

    填写本次参数，检查后运行

    需要提权时使用管理员启动；日常用 Enter，临时参数用 Shift+Enter。

启动前，你可能想知道。

默认命令与启动方案，有什么区别？＋

默认命令决定点击工具「启动」时执行什么；启动方案用于保存同一个工具的多种用法。参数占位符在方案中展开，普通默认命令继续按你填写的内容执行。

需要先把 Python 或 Java 加到系统 PATH 吗？＋

可以继承系统环境，也可以通过 Scoop 绑定具体版本。绑定环境仅对当前工具生效；相应解释器仍需在本机安装。Python 工具已有项目虚拟环境时，入口识别会优先建议该环境。

管理员启动，还会打开我选的外部终端吗？＋

当前外部终端接管适用于非管理员命令启动。启用管理员权限时会走系统提权流程，不保证使用所选外部终端。

配置备份，会包含工具程序和运行日志吗？＋

备份保存目录设置、工具元数据、命令、方案、环境绑定与使用统计。工具程序、笔记与运行日志不打包；换电脑时需要另行复制工具目录，并安装所需环境。
